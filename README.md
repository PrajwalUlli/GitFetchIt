# GitFetchIt

Browser Extension to download specific files or folders from a Github Repo

![video](assets/showcase.gif)

## Features

- Supports only Github.com
- Support single or multiple files download
- Download selected contents as a zip file with one click
- Maximum Selection Limit: 10
- Maximum Download Files: 10000

![screenshot](screenshots/firefox.png)
![screenshot](screenshots/chrome.png)

## Compatibility

- Chrome (Manifestv3)
- Firefox (Manifestv2)
